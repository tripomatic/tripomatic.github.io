## Free vs Premium

| | Free | Premium |
|---|---|---|
| Create, plan and edit trips | Yes, with [limits](/premium/free-plan-limits/): 5 unlocked trip days a month, 25 places per trip | No limits |
| Favorites, sharing, collaborators, duplicating trips, changing dates | Yes | Yes |
| Travel alerts in the app and the daily trip briefing | Yes | Yes |
| Push notifications for dangerous situations on your trip | No | Yes |
| Live flight status and flight change pushes | No | Yes |
| AI assistant | Preset questions, first answer only | Full chat, booking import from attachments, estimates of costs and durations |
| [AI day plans](/ai/plan-this-day/) | 3 per 24 hours | As many as you like |
| Optimize day (reorder stops for the shortest route) | No | Yes |
| Map styles | Streets, Minimal | Also Satellite, Outdoor, Winter |
| [Offline maps](/on-the-road/offline-maps/) | No | Yes |
| [Export to PDF, GPX, KML](/sharing-and-export/export-trip/) | No | Yes |
| Uploading [trip attachments](/sharing-and-export/trip-attachments/) | No | Yes |
| Navigation link by email | Yes (account needed) | Yes |
| Ads | Shown | None |
